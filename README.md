Netflix Clone

A Netflix landing page clone built using HTML and CSS.
This project was created to practice front-end web development skills by recreating the layout and design of the Netflix homepage.

Features
Responsive navigation bar
Hero section with background image
Styled buttons and layout sections
Movie and content showcase sections
Footer section with links
Clean and modern UI inspired by Netflix
Built With
HTML5
CSS3
Purpose of the Project

The purpose of this project was to improve my understanding of HTML structure and CSS styling by recreating a real-world website design.

This project helped me practice positioning, layouts, spacing, background images, Flexbox, and overall page structure while focusing on making the page visually appealing.

Challenges Faced

One challenge I faced was recreating the Netflix layout accurately while keeping the design responsive and organized. Styling the navigation bar and hero section was difficult at first because I had to work with positioning, spacing, and background images carefully.

Another challenge was managing the structure of different sections and making sure the content aligned correctly across the page.

What I Learned

Through this project I learned:

How to structure a landing page using HTML
How to style layouts using CSS
How to use Flexbox for positioning
How to work with background images
How to create responsive page sections
How to improve UI design and page organization
